## Core Project Structure

- **Root Directory**: Contains project configuration files and main entry points.
- **Apps Directory**: Houses the main applications (e.g., web, desktop).
- **Packages Directory**: Contains reusable modules and libraries.
- **Scripts Directory**: Includes utility scripts for project maintenance.
- **Docs Directory**: Contains project documentation and architecture diagrams.

## Key Files

- **package.json**: Project dependencies and scripts.
- **tsconfig.json**: TypeScript configuration.
- **turbo.json**: Monorepo configuration.
- **docker-entrypoint.sh**: Docker entry point script.
- **nginx.conf**: Nginx configuration for production.
